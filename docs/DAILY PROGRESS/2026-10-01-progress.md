## Biggest Lesson

- I learned to test dependencies with a clean install. My local `node_modules` included packages missing from `package.json`, so I only caught the issue when deployment failed on Render.
- I also learned that Render’s free tier sleeps after 15 minutes of inactivity, causing a slow first response (a cold-start delay). To address this, I researched possible solutions and set up UptimeRobot to ping the API every five minutes to keep it awake and reduce cold-start delays.
