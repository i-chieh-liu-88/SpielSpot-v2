## 3. 評論刪除驗證

新增檔案：[reviewRoutes.integration.test.js](../backend/src/routes/reviewRoutes.integration.test.js)。測試使用 Supertest 經過真正的 app、路由、requireLogin 與 controller，模擬 Clerk 與 Review model，不連線 Atlas，也不刪除真實資料。

| 情境 | 預期與實際結果 | 額外斷言 |
| --- | --- | --- |
| 本人刪除 | 200，success: true、data: null | 用正確 ID 查詢，deleteOne 呼叫 1 次 |
| 其他人刪除 | 403 | deleteOne 未呼叫 |
| 其他人偽造 body.authorId | 403 | deleteOne 未呼叫 |
| 未登入 | 401 | 不查資料庫，也不刪除 |
| 資料不存在 | 404 | deleteOne 未呼叫 |

這確認的是伺服器在模擬身分與資料下的權限行為；不代表真實 Clerk token、MongoDB 刪除或持久化已通過。
