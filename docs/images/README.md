# README visual assets

These files present the existing SpielSpot product. The cover composition does not add or change application features.

| Asset | Source and purpose |
| --- | --- |
| `spielspot-cover.svg` | Editable, self-contained cover composed from the real homepage and map captures below. Affine transforms, a forest-green background and soft shadows create the angled product presentation. No Twenty or Appwrite artwork was copied. |
| `spielspot-homepage.jpg` | Screenshot of https://spielspot.netlify.app/, captured October 19, 2026. Existing SpielSpot interface and illustration assets. |
| `spielspot-map.jpg` | Map panel from https://spielspot.netlify.app/playgrounds, filtered to Berlin and captured October 19, 2026. Contains no playground photograph. Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright); attribution appears in the capture and below the cover in README. |
| `spielspot-mark.svg` | SpielSpot S emblem, adapted from `frontend/src/components/atoms/Brand/Brand.tsx`, using brand green #166534. Includes a Hanken Grotesk font subset for consistent display. |
| `spielspot-brand.svg` | Earlier horizontal brand header retained as a reusable asset. Uses the same brand palette and Hanken Grotesk subset. |
| `Hanken-Grotesk-LICENSE.txt` | SIL Open Font License for Hanken Grotesk, sourced from the Google Fonts project. |

The SVG cover keeps the screenshot pixels unchanged inside its angled frames. Source URLs and capture date are also recorded in its metadata. Update the screenshot assets when the public UI changes; do not replace them with unverified feature mockups.
